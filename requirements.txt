#
# Two supported install modes (see ../REPOS.md):
#   1. Fresh install:  pip install -r requirements.txt        (pinned git refs)
#   2. Live host:      sibling checkouts at /opt/<repo>, exposed to the venv by
#                      site-packages/agent_voice_deps.pth. There the "install"
#                      is a `git pull` per repo, then a service restart.
